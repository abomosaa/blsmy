# ملاحظات موقع بلسمي

واجهة عربية RTL مبنية بـ **Angular 21 وTypeScript وHTML وCSS**، مع صفحات مستقلة وتصميم متجاوب وحركات ظهور بسيطة تتوقف عند تفعيل تقليل الحركة.

أعيد ترتيب الرئيسية وفق الموقع الأصلي: **المقدمة ← الحجز ← الإحصاءات ← الخدمات ← آراء الشركاء ← الشركاء ← صور التطبيق ← التذييل**. استُخدمت صور بلسمي الأصلية: 64 ملفًا محفوظًا محليًا، إضافة إلى 5 أيقونات للإحصاءات مستخرجة من الصفحة. بقيت الشعارات وهوياتها كما هي.

المحتوى يشمل 21 خدمة، و3 آراء شركاء بالنصوص والصور المنشورة، و25 شعار شريك، و5 صور فعلية للتطبيق. الإحصاءات والسجل التجاري والرقم الضريبي من الموقع الأصلي.

الحجز متاح بطريقتين: رابط مباشر إلى نظام بلسمي، أو طلب موعد عبر واتساب بخطوات اختيار الخدمة، إدخال البيانات، ثم مراجعة الطلب. البحث العام يفتح المنصة الأصلية، والدليل المحلي يعرض الشركاء من قائمة الشعارات ويسمح بالبحث بالاسم. روابط دخول المراكز وAPI وحالة الأنظمة تفتح وجهاتها الأصلية.
